# 自作高精度電子負荷デバイス 通信仕様書 (Ver 1.0)

本ドキュメントは、PCソフトウェアと電子負荷デバイス（ATmega328Pベース）間のシリアル通信プロトコルを定義する。

## 1. 物理層仕様 (UART)

| 項目 | 設定値 | 備考 |
| :--- | :--- | :--- |
| 通信速度 (Baud Rate) | 1,000,000 bps (1 Mbps) | 誤差 0.0% |
| データ長 | 8 bits | |
| パリティビット | なし (None) | |
| ストップビット | 1 bit | |
| フロー制御 | なし | |
| 通信方式 | 全二重 (Full Duplex) | |

## 2. データフレーム構造

全てのパケットは固定長バイナリ形式である。テキスト(ASCII)ではないため注意すること。

### 2.1 ヘッダ (Header)
全てのパケットの先頭には、同期用の2バイトが付与される。
- **Byte 0**: `0xAA`
- **Byte 1**: `0x55`

### 2.2 チェックサム (Checksum)
パケットの最後に付与される1バイト。
- **計算方法**: ヘッダを除くデータ本体（CMD/MODEから最終データまで）の各バイトを **XOR (排他的論理和)** したもの。
- 受信側は計算したCSがパケット末尾のCSと一致しない場合、そのパケットを破棄しなければならない。

---

## 3. コマンド仕様 (PC → デバイス)
**パケット長: 6バイト固定**
`[0xAA] [0x55] [CMD] [DATA1] [DATA2] [CS]`

| CMD | 名称 | DATA1 | DATA2 | 内容 |
| :--- | :--- | :--- | :--- | :--- |
| `0x01` | DAC A 設定 | High Byte | Low Byte | 電子負荷回路1の目標値設定 (12bit値) |
| `0x02` | DAC B 設定 | High Byte | Low Byte | 電子負荷回路2の目標値設定 (12bit値) |
| `0x03` | FAN 設定 | FAN1 PWM | FAN2 PWM | 0x00(停止) ～ 0xFF(全開) |
| `0x04` | システム制御 | Mode | (0x00) | 0:IDLE, 1:STANDBY, 2:STREAM |

---

## 4. テレメトリ仕様 (デバイス → PC)
**パケット長: 8バイト固定**
`[0xAA] [0x55] [MODE] [DATA1] [DATA2] [DATA3] [DATA4] [CS]`

| MODE | 名称 | DATA1 | DATA2 | DATA3 | DATA4 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `0x01` | 回路1データ | 電流(I1) High | 電流(I1) Low | 電圧(V1) High | 電圧(V1) Low |
| `0x02` | 回路2データ | 電流(I2) High | 電流(I2) Low | 電圧(V2) High | 電圧(V2) Low |
| `0x03` | ボードモニタ | サーミスタ1 | サーミスタ2 | ファン1 RPM | ファン2 RPM |

- **電流/電圧**: 符号付き16bit整数 (Big Endian)。
- **温度/ファン**: 8bit整数。ファンRPMはデバイス側でスケーリング(例: RPM/100)されている。

---

## 5. 運用フローとステートマシン

安全のため、デバイスは以下の状態遷移を行う。

### 5.1 IDLE (起動直後)
- **状態**: リレーOFF、DAC出力0V、計測停止。
- **PCの動作**: デバイスとの接続を確認。

### 5.2 STANDBY (準備完了)
- **トリガー**: PCから `CMD=0x04, Mode=1` を送信。
- **状態**: デバイスがリレーをONにし、アナログ電源を供給。
- **出力**: デバイスは1秒に1回、低速でテレメトリを送信。
- **PCの動作**: 電圧値が正常（入力電圧と一致）であることを確認。

### 5.3 STREAM (本稼働)
- **トリガー**: PCから `CMD=0x04, Mode=2` を送信。
- **状態**: 高速計測ループ開始。
- **出力**: デバイスは指定モード(CH1 or CH2)のデータを約1000Hz～2000Hzで送信。
- **PCの動作**: 波形描画およびDAC制御コマンドの送信。

### 5.4 安全停止シーケンス
PCソフト終了時や緊急時は、必ず **IDLEモードコマンド** を送信すること。
1. PCが `Mode=0` を送信。
2. デバイスがDACを0Vに落とす。
3. デバイスがリレーをOFFにする。

## 6. 実装上の注意
- **バッファ処理**: 1 Mbpsでは毎秒数千パケットが届くため、PC側は受信スレッドを分離し、ヘッダ `0xAA 0x55` を基準にしたリングバッファでの同期処理を強く推奨する。
- **タイムアウト**: 1秒以上パケットが途切れた場合、PC側は通信断線と判断し警告を出すこと。
